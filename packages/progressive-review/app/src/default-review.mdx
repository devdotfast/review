# Progressive Review

This build-time document proves the MDX review surface compiles. Runtime review
sessions render review documents stored under `~/.dev`, and the Map tab is
backed by the external `~/.dev` software map for this repository.

[`Review runtime`](anchors.reviewRuntime) opens the side peek.
