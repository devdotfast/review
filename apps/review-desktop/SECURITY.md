# Security Policy

Report suspected vulnerabilities in Review Desktop privately through GitHub
security advisories on this repository ("Report a vulnerability" under the
Security tab). Do not open a public issue for a security report.

Do not report Review Desktop issues to Microsoft. `code-oss/SECURITY.md` is a
retained artifact of the vendored Code - OSS tree and applies to Microsoft's
VS Code, not to this project. If a vulnerability originates in upstream
Code - OSS itself, report it to Microsoft per that file, and to us if it
affects Review Desktop.
