# Whiteboard for Cursor

Registers Whiteboard's MCP server with Cursor.

The Connect card in Whiteboard Desktop shows a Cursor install link
(`cursor://anysphere.cursor-deeplink/mcp/install?...`) that adds the same
server this plugin's `mcp.json` declares. Both require Whiteboard Desktop with the
`whiteboard` command installed (Settings → Command line).

## Listing

The marketplace listing is a manual submission at
<https://cursor.com/marketplace/publish>, made after this directory merges.
