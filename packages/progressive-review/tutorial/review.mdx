# Review Desktop: three-minute tour

## Welcome

This Review uses a real local TypeScript repository. Review documents connect
short explanations to live code and system views.

## Code is live

This path validates a checkout, creates an order, and writes it to storage.
Hover a typed symbol. Then use F12 or command-click to open its definition.

<AnchorLink anchor={anchors.placeOrder}>Open the order write path</AnchorLink>.

## Comments are threads

Move the pointer over the code above. A comment control shows in the left
gutter. Click it and write a note.

Select **Ask now**. An agent reads your note and answers in the same thread.
A real Review adds a second button, **Add to review**, that holds the note
until you submit. This tour has no review round to submit to, so it keeps
only the one button.

Every comment is a thread anchored to one part of the Review. Use the **+**
button in the toolbar to start a thread about the whole Review instead.
